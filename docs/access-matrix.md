## Teams participation

SharePoint visibility and Team participation are separate. The role's explicit `teamChannels`, `projectTeamMemberships`, `emergencyMemberships` and own department determine Teams navigation and direct-channel access. `teamsLanding` defines the primary landing; opening an internal SharePoint workspace does not add Team membership. Navigation omits groups with no accessible channels, and workspace Home panels use the same channel policy.

Switching to a role that has not joined the current context returns to that role's valid primary landing and drops the previous channel/file context. The Architecture department directory can list all six departments; inside Teams, a role sees only its own department. The external access hint suggests only another preview role authorised for that exact resource.
